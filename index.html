Windows

~50-80 MB ZIP Archive
Download for Windows

Installation Instructions:

  1. Download the ZIP file above
  2. Extract the ZIP file to a folder (e.g., Desktop)
  3. Open the extracted folder and you'll see DesktopPet_Windows.zip
  4. Extract this second ZIP file (DesktopPet_Windows.zip) to a new folder
  5. Open the newly extracted folder and you'll see the Desktop Pet folder
  6. Open the Desktop Pet folder
  7. Double-click the Desktop Pet Application file
  8. When prompted with "Windows protected your PC":
    • Click "More info"
    • Click "Run anyway"
    • This is safe - it's just Windows being cautious about unsigned files
  9. If you encounter DLL errors:
    • Try running Desktop Pet Launcher.bat instead
    • This launcher helps with DLL loading issues

Note: The double extraction is needed because the build creates a nested ZIP structure. If you have issues, try the launcher script!

System Requirements:

  • Windows 10 or later
  • 64-bit processor
  • 100 MB free disk space
  • DirectX 11 compatible graphics

macOS

~162 MB DMG Installer
Download for macOS

Installation Instructions:

  1. Download the DMG file above
  2. Double-click to mount the DMG
  3. Drag DesktopPet to Applications folder
  4. Important: Try to open the app from Applications folder
  5. You'll see a security warning with options "Close" or "Move to Trash" - click "Close"
  6. Go to System Preferences → Privacy & Security
  7. Scroll down to the Security section
  8. Look for "DesktopPet was blocked" message and click "Open Anyway"
  9. Try opening the app again - it should work now!

System Requirements:

  • macOS 10.15 (Catalina) or later

How to Use Desktop Pet

Get started with your new AI-powered desktop companion!

Set Up OpenAI API Key

  1. Go to OpenAI API Keys
  2. Sign up or log in to your OpenAI account
  3. Create a new API key
  4. Right-click on your desktop pet
  5. Select "Set OpenAI API Key..." from the menu
  6. Enter your API key and click OK

Your API key is stored locally and never shared with us.

Basic Controls

  • Right-click: Open the pet menu
  • Double-click: Interact with your pet
  • Click and drag: Move your pet around the screen
  • Press Tab: Place the pet at the desired spot
  • Assistant Mode: Right-click → "Assistant Mode" for AI chat

Voice Commands

  1. Enable wake word detection in Voice Settings
  2. Say your wake word (default: "Hey Pet")
  3. Speak your request clearly
  4. Try commands like:
    • "What's the weather in Miami?"
    • "Set a timer for 30 minutes"
    • "Remind me to call mom at 3pm"

Settings & Customization

  • Volume Control: Mute, Low, Medium, High
  • Font Size: Small, Medium, Large
  • Time Format: 12-hour or 24-hour
  • Timezone: Choose your local timezone
  • Wake Word: Customize voice activation phrase

Privacy & Security

  • We do NOT collect, store, or send any data to external servers
  • All settings and preferences are stored locally
  • Your conversations are not saved permanently
  • No personal information is collected or tracked

Troubleshooting

  • App won't start: Check antivirus settings, allow in security preferences
  • AI chat not working: Verify OpenAI API key and internet connection
  • Voice commands not working: Check microphone permissions
  • Weather not working: Check internet connection
